# Portafolio Personal - Matías Pulgar

Portafolio web responsivo con soporte para modo oscuro/claro y catálogo interactivo de proyectos.

🌐 **Sitio Web en Vivo:** [https://mpulgar.github.io](https://mpulgar.github.io)

## 🚀 Tecnologías Utilizadas

- **HTML5 Semántico**
- **CSS3 Moderno** (Variables CSS, Flexbox, Grid, Animaciones, Glassmorphism)
- **JavaScript (ES6+)** (Alternador de Modo Oscuro/Claro con `localStorage` y menú responsivo)
- **GitHub Pages** para alojamiento gratuito continuo

## 📂 Proyectos Destacados

1. **[CVATS](https://github.com/TheGrone/cvats)**: Sistema de gestión y filtrado de CVs compatible con ATS en React & TypeScript.
2. **[Control de Asistencia](https://github.com/TheGrone/control-asistencia)**: Sistema de gestión de turnos y asistencias con Python y base de datos relacional.
3. **[Portafolio Web](https://github.com/TheGrone/mpulgar.github.io)**: Este sitio web moderno y responsivo.
