Solución Android

¿Cómo subir y compartir tu app Android (CVAS) 100% Gratis?

Para que cualquier persona o reclutador pueda probar tu aplicación móvil sin pagar licencias de Google Play:

Paso 1: Generar APK

Compilar el archivo .APK

Si usas React Native con Expo, ejecuta npx eas build -p android --profile preview para compilar gratis en la nube. Si usas Android Studio, ve a Build > Build Bundle(s) / APK(s) > Build APK(s).

Archivo instalable listo
Paso 2: GitHub Releases

Subir a GitHub Releases

En tu repositorio TheGrone/cvats en GitHub, entra a Releases > Draft a new release, arrastra tu archivo .apk y presiona Publish. ¡GitHub te da un enlace permanente y gratuito para descarga directa!

Descarga directa en 1 clic
Paso 3: Appetize.io (Demo Web)

Simulador Android en la Web

Si quieres que lo prueben sin instalar nada, sube el .apk a appetize.io (es gratis). Te genera un teléfono virtual en la web para que cualquiera use tu app desde su navegador.

Prueba interactiva en navegador
